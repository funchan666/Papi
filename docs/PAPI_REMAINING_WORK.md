# Papi：当前完成情况和上线前待办

更新：2026-10-28。此清单以当前代码、配置和实际隔离环境检查为准。不要清理或覆盖现有设备上的旧档案、余额记录、购买记录和媒体。

## 已具备并已核验

- 用户协议和隐私协议已发布在正式 Supabase 的独立公开只读文件容器；地址配置在 `Papi/Resources/Localization/PapiPolicies.json`。两份协议使用用户提供的 `Papi_service2026@outlook.com`；邮箱实际收信及运营响应尚未验证。
- 本地版继续使用现有 Keychain 档案；登录要求勾选协议。线上协议再次确认和云账号接入的入口已准备，但当前线上协议版本尚未启用。
- 独立测试项目中验证了 Supabase Auth、私有 Storage、数据库防护、语音房/通话的 LiveKit 合成音视频、拉黑后的连接撤销，以及进行中注销后的连接清理、账号和个人文件删除。
- 在同一独立测试项目内的回滚事务中验证审核状态、审核事件幂等及普通账号不能审核。此项不是实际审核运营验收。
- iOS 模拟器构建通过。模拟器曾启动，但交互与显示核验未完成，不能当作真机验收。

## 仍需补齐：产品与工程

1. **旧数据和余额迁移**：梳理本地金币、历史购买、解锁、收藏、资料、媒体及社交记录如何安全迁移或保留。现有云钱包读取服务端余额，本地数据仍在设备上，但并未证明云端余额与本地余额已对账。不得先清理本地记录，也不得把客户端自报余额直接作为可消费的服务端资产。
2. **线上政策与支持**：验证提供的运营邮箱能够收信并落实响应；上线云功能前按实际数据流、存储期限和注销行为更新政策，并向用户收集必要的新版同意。
3. **审核和反滥用**：确定真实审核人员、举报通知、响应时效与应急处理；匿名注册需要防滥用策略。数据库审核接口通过隔离验证，不能代替运营团队。
4. **账号恢复和注销**：邮箱关联/恢复需要邮件发送服务、实际验证和冲突处理；线上注销的保留期限、附件与交易记录规则，以及跨设备验收仍待完成。正式注销开关保持关闭。
5. **语音房和通话**：使用真实签名 App 和设备检查麦克风、摄像头、后台/前台、权限、弱网、通话结束与拉黑；确认运维和成本后再开启服务端及客户端开关。当前不支持后台推送或 CallKit 接听。
6. **Apple 购买**：需要 App Store Connect 的应用和商品配置、App Store Server API 的 Issuer ID、Key ID、私钥以及 Apple 数字 App ID；完成沙盒交易、退款通知处理、补账和对账后再开启线上购买。仅提供 Apple ID 不能替代全部服务端凭据。
7. **发布和验收**：在真实签名设备上验证登录、协议 WebView、Keychain、云端完整流程、iPhone Duo 布局、网络异常和数据恢复。复核 App Privacy 信息与实际启用的数据处理一致。

正式语音、通话、线上注销开关和清理任务目前仍关闭；测试项目的临时匿名注册和调度已关闭。公开的 `papi-policies` 只存协议，用户媒体 bucket 仍为私有。
