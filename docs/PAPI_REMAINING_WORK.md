## 剩余事项

1. **真机验收**：用户将测试新版协议、创建云账号、钱包及咖啡书同步、私有媒体、关注/聊天、两台设备的语音房和通话、拉黑断连、注销、弱网和重新启动。测试前保留原设备数据；不能以隔离环境测试替代真机结果。
2. **账号恢复**：邮箱关联、SMTP 和跨设备找回尚未完成上线验证，当前客户端入口关闭。匿名账号的会话丢失可能导致无法找回，暂时保留设备与会话。
3. **审核和防滥用**：上线给公众前需落实审核人员、举报响应、内容处理以及匿名注册防滥用；数据库能力不等于已有人实际审核。
4. **Apple 购买**：客户端已改用 StoreKit 1 的商品请求和交易队列，购买开关仍关闭。交易号验签接口仅是本地草稿，尚未部署；需要 App Store Connect 应用与商品配置、Apple 数字 App ID、App Store Server API 的 Issuer ID、Key ID 和私钥。启用前还须完成取消及中断订单的安全撤销/对账（现有未完成云端订单会阻止注销）、退款通知、反向记账、旧交易恢复，以及沙盒/真机交易验收。不得仅凭修改客户端开关开启收款。
5. **注销后的新账号**：已增加保留本地档案并重新创建线上账号的入口，旧账户未完成的冲煮写入会保存为本地备份；仍需在真机验证中断、重新同意和新账号创建。
6. **数据保留与隐私**：进一步明确被删除用户的其他人所拥有的消息附件保留期限与清理规则、服务日志及财务记录的具体期限；公开运营前核对 App Privacy 配置和协议。
7. **后台通话**：目前仅支持前台呼叫提示；没有后台推送和 CallKit 接听。
8. **新增动态与语音房功能**：在两台真机上验证头像及资料跳转、精选与真实动态的举报/拉黑、点赞和评论审核、房间消息与礼物、麦克风权限，以及弱网重试。精选评论的审核与举报见 `backend/MODERATION_RUNBOOK.md`；仅部署队列不代表有审核人员或响应机制。
