# Papi 冲煮台与双杯品鉴

新功能全部为 Swift 原生实现，沿用 Papi 的咖啡棕、蜜桃色与奶油色。2026-10-26 按原设计纠正第二个 Tab：恢复 Voice 与咖啡杯的选中/未选中图标，打开 Coffee tables。Brew bench 改由“我的 → Brew bench”进入，冲煮记录、已解锁配方、计时与余额不迁移、不清除，仍保持明确的非联网能力说明。

## 完整路径

Brew bench → 选配方 → 填豆名/研磨备注 → 调整 8–40 g 粉量 → 查看随粉量换算的水量与冰量 → 开始 → 按时间提示注水 → 暂停/继续 → 保存这一杯 → 填写主观风味 → 再冲一次或选择两杯比较 → 保存品鉴。

配方、冲煮记录、时间锚点、编辑中的品鉴备注、比较选择与偏好均进入同一个受保护账户快照。切换 Tab、页面与容器不重建计时器或购买对象。计时用开始/暂停日期与累计秒数恢复，不靠后台循环保活；离开后仍按经过的时间呈现，不承诺后台响铃。

已有记录的“Brew this again”复制豆名、粉量和研磨备注，保存基准杯 ID。新杯完成后与原杯自动配对；用户仍需自己品鉴，程序不生成虚假分数或所谓 AI 味觉诊断。比较列出记录中的差异，对不同豆名或多个变量给出适当解释。保存品鉴时冻结当次差异与主观评分，后续改笔记不会改写旧品鉴。

## 字体与原创图片

内置两组 OFL 来源字体：Fraunces 的咖啡编辑衬线字形，以及 Nunito Sans 的正文/数字字形。源文件在 ProjectMaterials/Typefaces，原授权在 Papi/Resources/Fonts。为控制体积派生为 Papi Editorial 与 Papi Counter 两个项目字族，各三种字形，共六个 TTF，约 325 KiB；原作者版权和授权保留。派生字族命名不表示字体原设计由 Papi 创作。

UIAppFonts 注册后，所有可编辑应用文字通过 CoffeeType 离线使用本地字体，支持 Dynamic Type。拉丁、扩展拉丁和越南文常用字形已保留；阿拉伯文、泰文、韩文及不包含的货币字形使用 iOS 已安装的离线字形回退。原始配套图片中自带的文字仍属于图片内容，不会被字体 API 改写。没有在线字体请求。

字体来源：[Fraunces](https://github.com/google/fonts/tree/main/ofl/fraunces)、[Nunito Sans](https://github.com/google/fonts/tree/main/ofl/nunitosans)。下载记录与字形名称见 TYPEFACES.json，原字体和授权均已保存。

三个原创光栅素材分别用于冲煮台、双杯品鉴和滴滤器导航；通过 Image 2 技能的 Host-Native 流程调用内置生图工具制作，不指定或推断宿主背后的模型版本。原件和提示词见 ProjectMaterials/UIAssets/BrewBench，整屏设计参考在 ProjectMaterials/DesignReferences/BrewBench。设计参考是生成的视觉参考，不是 App 运行截图；其标签细节以实际原生代码为准。
