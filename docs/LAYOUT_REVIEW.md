# Papi 布局复核与修正

2026-10-23。覆盖现有 SwiftUI 页面、顶部返回区、底部按钮、输入栏、弹窗、媒体预览和自定义导航。沿用既有主题色、原创素材、本地字体和业务状态；没有新增远端服务或应用依赖。

## 已修正的源码约束

| 部位 | 问题与处理 |
| --- | --- |
| 顶部返回与操作 | 返回按钮保留 44 点点击区域和独立布局优先级；右侧操作不被标题挤压。长标题通常两行，可用高度不足时一行显示；完整标题保留在文字的无障碍语义中。聊天的视频操作移入可滚动内容，避免与用户姓名及更多按钮争抢同一行。 |
| 照片上的导航 | 个人详情的返回/更多区、我的页面的编辑/设置按钮使用主题浅色承托，避免深色素材使图标难以识别。 |
| 聊天、评论、咖啡桌输入 | 共用输入栏与稳定身份的自定义 Layout，按实际宽度决定一行或两行；采用底部 inset 为列表预留空间。短窗口或键盘缩小可用高度时减少输入可见行数并优先使用紧凑横排；输入值和草稿绑定不变，不通过重建页面适配键盘。 |
| 输入栏反馈 | 发送和保存图标增加浅色按钮背景，防止深色图标与咖啡色栏位混在一起；主要图标按钮仍保留至少 44 点点击区域。 |
| 确认与反馈弹窗 | 确认、欢迎、成功回执、账号操作共用按内容高度测量的容器。短内容居中，长内容在可用高度内滚动；宽高不再强制至少 44 点而突破小区域。出现时通过响应链收起键盘，保留草稿。 |
| 弹窗期间的导航 | 记录当前弹窗实例；存在弹窗时暂停底部 Tab、侧滑返回和 sheet 手势关闭，防止离开确认操作上下文。弹窗自身的确认/取消和程序化跳转仍可操作。 |
| Duo 遮挡避让 | 一个控制组只整体避让一次，避免组内图标各自平移后相互覆盖；保留容器测量、系统内容边距与当前遮挡区数据。 |
| 底部导航 | 侧栏可纵向滚动，导航标签允许随字体换行；页面根节点仍稳定挂载。 |
| 充值页 | 余额随商品列表滚动。常规高度保留底部购买区；横屏、较短窗口或辅助大字体将购买操作放入列表中，避免固定余额和固定按钮挤掉正文。购买仍只由点击触发，原商品 ID、数量、交易及恢复逻辑未改。 |
| 多按钮区域 | 关注/聊天/礼物、数量与剂量调整、计时操作、相机预览操作和登录协议入口根据内容宽度横排或纵排；不通过压缩按钮文字硬塞一行。 |
| 短屏页面 | 录音、相机预览、等级、安全操作和不可用内容页面补充可滚动正文，保留返回区和原有操作。相机和录音所有者、权限及生命周期处理不变。 |
| 图片与网格 | 首页及咖啡桌在窄容器或辅助大字体下允许单列；礼物和充值商品最小列宽随字体缩放。咖啡桌标题不再硬塞进固定高度的图片叠层；窄屏配图标题移到图片外，保留完整可编辑文字。 |
| 播放器 | 播放控制与进度条按可用宽度排列，错误文字和重试入口可滚动；播放器对象与播放状态保留在原来的所有者中。 |

背景仍延伸到屏幕边缘。前景保留系统遮挡和键盘避让，没有给页面整体添加忽略键盘安全区的设置。
