## 真实差异化，而非只换名字

- **冲煮台**：两份免费配方，按粉量缩放热水/冰量；真实时钟锚点控制阶段提示，支持暂停、继续、离开与重启后的时间恢复。界面明确显示目标水量，不冒充蓝牙秤、温度计或浓度仪读数，不承诺后台响铃。
- **重冲与双杯品鉴**：从自己已保存的一杯复制豆名、粉量和研磨备注，保留 baselineCupID；完成后自动关联原杯与新杯。对照豆名、器具、粉量、水量、冰量、温度和研磨备注，区分一个设置变化、多个设置变化、设置相同和豆名不同；不把主观风味分数当实验室测量或因果结论。
- **品鉴快照**：保存当次对照项、两杯主观分数和用户备注。之后修改杯子品鉴笔记，不会改写旧次品鉴快照。删除杯子会清理相关比较与失效的重冲引用。
- **配方经济**：120 / 180 / 240 金币各解锁一次，账户内复用免费；记杯、重冲、品鉴与所有聊天类功能免费。充值页逐项说明费用，确认后原子扣币并保存解锁，余额不足保留输入并引导充值。
- **原创视觉**：Image 2 Host-Native 流程生成冲煮台、双杯品鉴插图与滴滤器图标，另保存整屏设计参考；真实页面仍为 SwiftUI 可编辑文字与交互。没有把设计参考整图冒充运行截图。

竞品核对仅使用 [Filtru 官网](https://filtru.coffee/) 与 [Beanconqueror 官网](https://beanconqueror.com/)。两者已有冲煮指导、记录或数据能力，因此不将“加一个计时器”视作独创性证明。本项目的评估依据是完整用户路径、自己的内容与视觉、咖啡领域记录关系，以及与其社区笔记的结合；不能据此断言其他产品绝无相似功能。

## 命名与数据兼容

源码按 Appearance、CoffeeDomain、Persistence、Media 和 CoffeeHouse 下的咖啡业务目录整理。主要实体为 CoffeeArchive、CoffeePassport、CoffeeMoment、TastingReply、CoinMovement、FollowingConsent、PourSession、BrewRecord、CuppingFlight、BrewVariableChange。页面参数采用 memberID、momentID、recipeID、cupID 等业务身份。

重命名的 Codable 属性显式保留旧 CodingKeys；原 Keychain service、访客 UUID、交易 ID、订单 token、历史媒体别名及审核状态不随命名重置。详情见 COFFEE_DOMAIN_MIGRATION.json 和 ARTWORK_ALIASES.json。标准的 id、token、CodingKey、Apple API 名称保留其原本含义；命名变化本身不是 4.3 免责依据。

## 内容与安全

- 19 张咖啡图与 8 张人物图逐项检查；21 段源视频各抽取 10%、50%、90% 帧查看，之后仅打包 17 段咖啡主题片段。接触表见 ProjectMaterials/Inventory。检查不证明完整视频全时段安全，也不证明素材授权。
- 人物姓名、咖啡简介、内容标题及说明已改为贴合对应画面的文字；人物仍明确是咖啡图集中的展示资料，不伪装成在线联系人。没有添加虚假好友、消息、粉丝、房间占座或点赞。
- 分类举报保留证据，列表不再展示被举报内容，活动页也不回显其内容摘要。拉黑继续过滤动态、回复、个人页、房间与聊天；解除不自动恢复关系。
- CommunityContentPolicy 对拟发布文字、回复、资料和消息做有限的多语言前置筛查。它不是完整的图像/视频审查系统；线上开放前仍需要实际审核服务、补充反绕过策略与申诉/处理流程。
- 投稿继续先进入私有审核队列，无自动通过或伪造审核回执。真实关系确认不存在时，不开放私聊发送或视频通话。保留明确的未送达、未连接与私有保存说明，用自然文案表达，不隐瞒能力边界。
- 摄像头私密预览仅申请摄像头；视频操作按用途请求双权限，录音使用 iOS 17+ AVAudioApplication 的真实麦克风授权。应用不会伪造系统授权窗口。

## Framework 与 Assets.car

当前 target 是原生 SwiftUI / UIKit，无第三方包或预编译 Framework。系统 StoreKit、AVFoundation、PhotosUI 等用于实际功能。没有可供当前仓库比较的其他产品二进制；本轮也未构建 Assets.car，所以没有二进制相似度测量或“机审通过率”结论。资源改名用于描述内容并保留旧引用；压缩用于体积和加载效率，不能视为规避审核的证明。

## 仍需运营方提供或完成

1. 有效的公开支持/举报受理邮箱或网页及运营信息。已向用户询问，未收到值前不编造地址；原“联系我们”按钮按先前要求保持移除，真实联系信息可进入共用协议页。
2. 若作为在线社区发布，接通真实用户关系确认、消息/通话、审核与举报受理处理；所有用户与审核人员应看到相同功能。当前用户决定暂不接服务，本轮遵循这一范围。
3. 在正式 App Store Connect App 下配置/核对 9 款商品及签名，执行必要的系统购买和取消/待批准/恢复/退款验证；资源与肖像权利也需确认。
4. 编译、实际字体呈现、长译文、Duo 开合/分屏、重启持久化和完整音视频检查。本轮遵循不编译、不测试、不运行的默认要求。
