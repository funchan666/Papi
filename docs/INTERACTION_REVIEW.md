# Papi 按钮与页面跳转复核

2026-10-23。针对前一轮布局调整进行源码检查，覆盖 30 个 Swift 文件中的按钮、手势、25 个页面目的地、6 种根弹层路由及局部协议、录音、相机和照片选择器。未编译、未运行测试或 App，未发起 Apple 商品请求和支付。

## 本轮修正

| 场景 | 修正与保留的行为 |
| --- | --- |
| 举报页返回 | 从安全菜单进入举报类型页时，返回先回到安全菜单；直接打开举报弹层仍正常关闭弹层。提交成功继续保存举报、隐藏内容并关闭弹层。 |
| 确认与关闭 | 通用确认弹窗每个实例只执行一次确认或取消，防止连续点击重复扣币或重复删除。所有调用点均核对了关闭对应状态的分支。全局反馈以回执 ID 区分实例，旧回执的关闭动作不能关闭新回执。 |
| 弹层到个人页或充值页 | 先关闭根弹层，等 `onDismiss` 后再跳转。短时间重复点击只保留一个待跳转目的地，当前栈顶相同页面不再重复入栈；登录状态变化会清除待跳转页面。 |
| 聊天发送 | 空草稿或照片导入中不可发送。照片导入从选择时锁定访客身份，结束后恢复按钮并清空选择器状态，允许再次选择同一照片。非空草稿仍在真正发送时检查互关；没有把互关门槛改成假好友或自动关注。 |
| 动态素材 | 导入过程中暂停拍照、录像与提交入口，并在动作入口复核导入状态，防止两个异步结果覆盖同一草稿。选择时锁定访客身份，完成后重置选择器状态。 |
| 充值购买 | 查询单个商品期间离开充值页或离开前台，取消本次尚未发起的购买。页面访问标识失效后，即使回到充值页或前台，旧查询也不会自行拉起支付。原生购买已经开始后，仍由原来的交易交付和恢复流程处理结果。 |

## 已核对的源码链路

- 返回与关闭：自定义导航栏的环境 `dismiss`、举报页局部返回、弹窗确认/取消、sheet 手势关闭、账号变化的路由重置。沿用上一轮弹窗实例登记与解除机制：弹窗出现时暂停底部 Tab、侧滑返回和 sheet 手势，实例消失时解除对应登记。
- 页面入口：首页动态和作者、评论作者、聊天头像/姓名、关系列表、个人页聊天/礼物、充值、背包、等级、设置、黑名单、语言、统一协议页、咖啡豆/咖啡馆、咖啡桌、冲煮记录及双杯品鉴。页面与弹层枚举都有对应渲染分支，未发现空按钮回调。
- 业务写入：关注与好友请求保持原同意规则；举报、拉黑、解除拉黑依赖本地保存结果；发帖不自动审核；礼物收藏和配方解锁保留扣币确认；登出/删除仍先检查未完成购买。
- 聊天：`sendChat` 在动作时执行 `requireMutual`，校验草稿和附件后一次写入本地待发送记录，成功保存才清空草稿。没有聊天扣币、假回复或伪造已送达。视频操作仍先校验互关，预览页继续使用真实相机/麦克风权限及既有停止逻辑。
- Apple 购买：仍仅在点击 Buy 后执行唯一的 `Product.products(for:[pack.id])`；7 个指定商品的金额与 ID 保留，新增 2 个商品保留。商品种类/价格校验、购买互斥、购买前保存订单归属及金币数量、交易验证、重复交付保护、保存成功后 finish、退款及未完成交易恢复均保留。布局位置切换没有新增商品查询或购买副作用。
- 输入与尺寸变化：输入控件由稳定的自定义 Layout 排列，草稿仍来自原持久化绑定；购买忙碌状态归属 `AppleCoinCounter`，不随购买按钮在列表内/底部切换而重置。未改变持久化字段和媒体会话所有者。

## 静态检查

- `Scripts/inspect_project.py`：源文件入组、资源、字体、多语言、商品配置等检查无发现。
- 全部 30 个 Swift 文件的独立 tree-sitter 语法树检查无未解决项，见 `SWIFT_SYNTAX_INSPECTION.json`。两处既有紧凑乘法表达式仅在解析器输入的内存副本补空格，源码未因此修改。
- `git diff --check`：通过。相关按钮动作、异步回调及状态复位已做源码差异复核。

使用 UI Design Reference、UI Taste、Design Skill、Impeccable、Duo 与 Ponytail 的适用原生 UI/静态复核规则，沿用项目素材与主题，没有增加美术资产或依赖。

静态检查不等于运行验收。未做 Swift 类型检查、构建、测试、模拟器、真机点击、键盘/弹窗运行验证、Duo 设备验证或 StoreKit 沙盒/真实支付验证；本地版本也未新增远端聊天和审核服务。

参考：[Apple DismissAction](https://developer.apple.com/documentation/swiftui/dismissaction)、[sheet 的 onDismiss](https://developer.apple.com/documentation/swiftui/view/sheet(item:ondismiss:content:))、[StoreKit PurchaseAction](https://developer.apple.com/documentation/storekit/purchaseaction)。

## 2026-10-26 登录加载反馈

点击登录后显示原 Papi 图标的轻微呼吸动效与主题纸张弹层，文字为 `Opening your coffee book…`，沿用当前语言。减少动态效果时停用呼吸动效，背景继续全屏 Fill，弹层沿用可用区域测量与滚动规则。

登录保存放到后台任务，至少保留 450ms 的可读过渡；较慢写入不再额外等待。完成 Keychain 写入及读回后才发布登录状态和首页。加载状态由 store 单独管理且不持久化，防止重复点击；期间暂停普通提交、重载、账号变更和新购买，避免异步快照被并发更新覆盖。保存失败结束加载并使用原有错误提示与存储重试，欢迎奖励、唯一流水和协议字段仍与登录状态一次保存，不模拟网络认证。

登录方法的唯一调用点已更新为异步调用；本轮仅执行资源/配置检查、独立 Swift 语法树解析和差异检查，未编译、测试或运行验证动效与 Keychain。非阻塞时钟接口参考 [Apple ContinuousClock.sleep](https://developer.apple.com/documentation/swift/continuousclock/sleep(until:tolerance:))。
