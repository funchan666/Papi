# Papi 云端内容目录

更新：2026-10-26。按用户要求，ContentImages 和 ContentVideos 的全部有效内容改用指定 HTTPS 链接，原件目录与对应 App 内容副本已删除。

## 覆盖

`Papi/Resources/Media/CoffeeCollection.json` 为唯一内容路径清单，共 60 张图片、21 个视频。图片保持原文件名与扩展名，使用 `/pp/`；视频使用 `/vv/`。基址为用户指定的 Cloudflare R2 公共域名。它是随包的固定媒体目录，不读取远端功能配置或执行远端代码。

- 19 张咖啡图片在首页动态、详情和咖啡探索中使用。
- 41 张人物图分别绑定独立预览资料。首页 Around the coffee table 可横向浏览全部人物，并进入对应个人详情和照片页；首批 8 个用户 ID 和头像映射保持。
- 21 个视频均有首页动态和播放器入口，其中 4 个城市/人物片段归入 Between cafés。40 条素材动态共用点赞数字、评论、安全菜单和原有过滤逻辑。

人物名称和内容互动均为明确标注的素材预览，不代表照片中人物的真实身份或在线活动。没有自动添加好友、回关、同意申请或写入聊天消息。

## 加载与连续性

CoffeeArtwork 的旧别名继续映射语义资源名；保存的帖子、收藏、举报和头像无需重写。CoffeeMedia 统一区分固定云端素材与用户设备的 `local/<guest>/<file>`，后者的保存、删除和草稿处理不变。

图片按需通过 URLSession 读取并下采样，使用 64 MiB 内存图片缓存和 32 MiB URL 响应磁盘缓存，单主机最多 4 条连接；同一素材复用正在执行的任务。视频使用 AVPlayer 直接读取 URL；封面从实际视频异步获取，最多并发 2 个并设置 20 秒生成超时。页面离开或后台会暂停播放，时长变化可更新进度条。图片失败使用项目原有占位；重新进入或回到前台可重试，播放器失败提供 Retry。

运行时下载缓存不属于随包原件。未预先把 81 个文件下载回项目，也未删除设备内用户自行导入的媒体。

## 清理与检查

`REMOTE_MEDIA_INSPECTION.json` 记录全部 81 条 HTTP 200、与原件完全相同的长度和 ETag/MD5；21 个 MP4 均返回 HTTP 206 的 64 字节范围读取，并有 MP4 头。原视频元数据为 H.264/AAC。以上只验证网络资源与源文件元数据，不代表 iOS 解码或播放通过。

`REMOTE_MEDIA_CLEANUP.json` 记录 169 个原件/运行时文件移除，共 130,101,270 字节。运行时资源源文件目前约 7 MiB，实际值见 STATIC_INSPECTION.json；没有测量 IPA 或安装体积。设计参考、UI 图片、原创背景和字体保留本地。
