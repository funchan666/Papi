# Papi 项目素材

应用已创建 SwiftUI 原生工程，礼物与背包保留，认证使用持久化本地访客一键登录。

- `DesignReferences/Lanhu/`：咖啡社区分组的 39 张设计原稿及来源清单。
- `UIAssets/`：用户提供的 105 张原创 UI 图片；`Generated/` 另存补充的语音房纯背景与提示。
- `ContentImages/`：60 张用户提供的照片，八张已选人物照片经用户授权固定绑定独立示例资料，其余照片保持原有来源映射。
- `ContentVideos/`：21 个用户提供的视频；运行时已显式导入并配对真实首帧封面。
- `Inventory/`：素材联系表与开发用清单。

原始文件全部保留。该目录未加入 App target；运行时副本在 `Papi/Resources/`，来源映射见 `docs/ASSET_MANIFEST.json`。详细现状见根目录 README 和 `docs/HANDOFF.md`。
